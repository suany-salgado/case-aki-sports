
# AKI Sports

### Plataforma Digital para o Ecossistema Esportivo

**Categoria:** Desenvolvimento de Produto Digital  
**Atuação:** Product Development | Full-Stack Development  
**Status:** Em desenvolvimento

---

## Sobre o projeto

O AKI Sports é uma plataforma digital desenvolvida para conectar profissionais, estabelecimentos e praticantes de atividades esportivas.

O produto busca centralizar funcionalidades de gestão e facilitar a interação entre os diferentes participantes do ecossistema esportivo.

## O problema

Profissionais e estabelecimentos esportivos precisam administrar alunos, atividades, agendas e informações operacionais, muitas vezes utilizando ferramentas desconectadas.

## A solução

Desenvolvimento de uma plataforma que reúne funcionalidades voltadas à gestão e à experiência dos usuários.

Entre os módulos previstos ou em desenvolvimento:

- Gestão de alunos e profissionais
- Organização de treinos e atividades
- Agendamento e gerenciamento de aulas
- Gestão de estabelecimentos esportivos
- Diferentes níveis de acesso por perfil de usuário

## Tecnologias

- Next.js
- React
- TypeScript
- Supabase
- PostgreSQL
- Tailwind CSS
- Integrações com APIs

## Minha atuação

Concepção do produto, análise de processos, definição de funcionalidades, modelagem da solução e desenvolvimento da aplicação.
